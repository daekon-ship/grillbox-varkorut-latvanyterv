# GrillBox Várkörút Székesfehérvár — Prémium látványterv

Street-food weboldal látványterv a GrillBox Várkörút (8000 Székesfehérvár, Várkörút körforgalom) számára.

**Megjegyzés:** Ez LÁTVÁNYTERV / demó — nem éles weboldal. A kosár és a rendelési folyamat front-end demó, nincs valódi fizetés vagy backend.

## Nézet

Az oldal statikus HTML/CSS/JS — bármelyik statikus tárhelyről működik (GitHub Pages, Netlify, stb.).

## Főbb funkciók

- Teljes képernyős hero valódi GrillBox ételfotóval, parázs-effektekkel
- „MIT KÉRSZ MA?” kategóriaválasztó (burgerek, lepények, grilltálak, doggyk, desszertek)
- Étlap preview valódi Wolt/foodora adatokból, product modal + működő demo kosár
- Rendelési opciók: helyben / elvitelre / Wolt / foodora / telefon (+36 20 428 4164)
- Google-értékelés (4.6★, 380+), helyszín + nyitvatartás blokk
- Teljesen reszponzív, mobilon sticky rendelősáv, `prefers-reduced-motion` támogatás

## Adatok

Árak és termékek a nyilvános Wolt/foodora profilról származnak (a kutatási anyagok lokálisan, a repóban nem publikusak). Nyitvatartás és egyéb adatok a legfrissebb publikus forrásokból.
